# Show tests

Run `rhinodiet test --show` in the project directory. Show that output to the user.

That command reads `.rhinodiet/tests/history.json`. Do not replace it with a remembered summary. If the output says there is no history, say so.

Keep the command list from the output. If the history page is already up, keep its URL. If it is not, keep the line that tells the user to start it.
